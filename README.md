# Jos Dore — Site Corporate & Écosystème

> Maintenance informatique, infogérance, boutique en ligne et jeux éducatifs au Bénin.

## 🚀 Démarrage

1. Ouvrir le dossier `jos-dore-corporate` dans VS Code.
2. Installer l'extension **Live Server**.
3. Faire un clic droit sur `index.html` → **Open with Live Server**.

> ⚠️ **Important** : Les chemins d'accès aux fichiers (CSS, JS, images) sont absolus (`/ressources/...`). Il est donc obligatoire d'utiliser un serveur local (Live Server) pour visualiser le site correctement.

## 🛠️ Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript (Vanilla).
- **Backend & Base de données** : Supabase (Authentification, profils).
- **PWA** : Manifest, Service Worker (mode hors-ligne et installation).
- **Icônes** : Uicons (Flaticon).
- **Polices** : Poppins & Inter (Google Fonts).

## 📂 Structure du projet

- `index.html` : Page d'accueil.
- `boutique.html` / `produit.html` : E-commerce (matériel, logiciels, livres, ebooks).
- `academie.html` : Formations en ligne.
- `jeux.html` / `jeu.html` : 31 jeux éducatifs (Quiz, Arcade, Mémoire, Anglais).
- `outils.html` / `outil.html` : Outils gratuits (Calcul TVA, QR Code, etc.).
- `contact.html` : Formulaire de contact et carte Google Maps.
- `ressources/` : Contient tous les fichiers CSS, JS, et images.
